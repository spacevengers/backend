# API contract (Go backend)

Base path: `/api`. Interactive OpenAPI is not generated by the standard
library server; this document is the contract.

## Conventions

- JSON responses; timestamps are ISO-8601 UTC with `Z`.
- List endpoints return `{items, total, limit, offset}`.
- Dates accept `YYYY-MM-DD` or RFC3339 datetimes. Date-only `end` values are
  inclusive through 23:59:59.999999 UTC.
- `bbox` is `west,south,east,north` (or `world`).
- Admin-only writes use `X-Admin-Token` when `ADMIN_TOKEN` is configured.
  With an empty token, local development endpoints are open.
- Errors use `{"detail": "..."}`.

## Observations

### `GET /api/observations`

| Parameter | Meaning |
| --- | --- |
| `sensor` | `MODIS` or `VIIRS` |
| `satellite` | Normalized platform |
| `source` | FIRMS source ID |
| `processing` | `SP` or `NRT` |
| `start`, `end` | Acquisition-time range (UTC) |
| `bbox` | Bounding box |
| `confidence_class` | `low`, `nominal`, `high` |
| `min_confidence`, `max_confidence` | Numeric confidence range |
| `min_frp`, `max_frp` | FRP range (MW) |
| `daynight` | `D` or `N` |
| `limit`, `offset` | Pagination (`limit` 1–5000) |
| `sort_by` | `acquired_at`, `frp`, `confidence_numeric` |
| `order` | `asc` or `desc` |

```bash
curl "http://localhost:9999/api/observations?sensor=VIIRS&start=2024-01-01&end=2024-01-31&bbox=33.5,-5,42,5.5&limit=100"
```

### `GET /api/observations/geojson`

Same filters; returns a GeoJSON `FeatureCollection` plus
`meta.total/returned/truncated`.

### `GET /api/observations/{id}`

Full record including the original `raw` CSV row.

## Harmonized output

### `GET /api/harmonized-observations`

Filters: `run_id` (defaults to latest completed run), `start`, `end`, `bbox`,
`min_frp`, `max_frp`, `composed_only`, `include_members`, `limit`, `offset`.

```json
{
  "id": 10,
  "cluster_uid": "…",
  "run_id": 1,
  "centroid_latitude": -1.29,
  "centroid_longitude": 36.82,
  "start_time": "2024-01-01T10:30:00Z",
  "end_time": "2024-01-01T10:32:00Z",
  "observation_count": 2,
  "modis_count": 1,
  "viirs_count": 1,
  "satellites": ["Suomi NPP", "Terra"],
  "total_frp": 22.5,
  "mean_frp": 11.25,
  "confidence_summary": {"high": 2},
  "uncertainty": {"spatial_radius_km": 0.06, "time_span_minutes": 2.0},
  "members": []
}
```

### `GET /api/harmonized-observations/{id}`

One cluster with members and their observations.

## Statistics

### `GET /api/statistics`

Accepts observation filters (except pagination). Returns:

- totals by sensor;
- coverage by sensor (time and bounding box);
- counts by satellite and date;
- confidence-class counts;
- FRP summaries (`min`, `p50`, `mean`, `p95`, `max`).

Percentiles are computed in the API process. For very large filtered sets,
aggregate by date/sensor first.

## Comparisons

### `GET /api/comparisons?run_id=…`

Returns:

- match count;
- spatial-distance and time-delta distributions;
- VIIRS/MODIS FRP ratio and difference distributions;
- counts by satellite pair;
- unmatched MODIS/VIIRS counts;
- a note that these are internal consistency metrics, not ground truth.

## Metadata

### `GET /api/metadata`

Schema version, coverage per sensor, products present, supported FIRMS
sources, recent ingestion/harmonization runs, and field-semantics notes.

## Ingestion

### `POST /api/ingestion/runs` *(admin)*

```json
{
  "source": "MODIS_SP",
  "bbox": "33.5,-5.0,42.0,5.5",
  "start_date": "2024-01-01",
  "end_date": "2024-01-31"
}
```

Queues a background run and returns `202`. Requires `FIRMS_MAP_KEY` on the
server. With `SYNC_JOBS=true`, the run executes inside the request.

### `GET /api/ingestion/runs` and `GET /api/ingestion/runs/{id}`

Run status and counts; detail includes stored row errors.

## Harmonization

### `POST /api/harmonization-runs` *(admin)*

```json
{
  "method": "baseline",
  "start": "2024-01-01T00:00:00Z",
  "end": "2024-01-31T23:59:59Z",
  "bbox": "33.5,-5.0,42.0,5.5",
  "max_distance_km": 2.0,
  "max_time_minutes": 180
}
```

Queues a run. `GET /api/harmonization-runs` lists runs;
`POST /api/harmonization-runs/{id}/execute` retries a pending/failed run.

### `GET /api/harmonization-runs` and `GET /api/harmonization-runs/{id}`

Run status, counts, parameters, filters, and metrics.

### `POST /api/harmonization-runs/{id}/predictions` *(admin)*

Imports ML outputs for the clusters of a completed run:

```json
{
  "model": "lightgbm-2026-11-15",
  "predictions": [
    {"cluster_uid": "abc...", "p_modis_detect": 0.73, "frp_calibrated": 11.25}
  ]
}
```

At least one of `p_modis_detect` and `frp_calibrated` is required per item.
The import is all-or-nothing: unknown or duplicate cluster UIDs, probabilities
outside `[0, 1]`, or negative calibrated FRP reject the batch.

## Frontend integration adapters

These endpoints preserve the native API but return the shapes used by the
TerraWatch frontend. See `docs/integration.md`.

| Endpoint | Returns |
| --- | --- |
| `GET /api/integration/observations` | `Observation[]` |
| `GET /api/integration/harmonized-observations` | `HarmonizedObservation[]` |
| `GET /api/integration/statistics` | `{counts, harmonized}` |
| `GET /api/integration/firms` | compact live-map payload (`modis`, `viirs`, `links`, `rule`, `clusters`) |
| `GET /api/integration/archive/summary` | monthly calendar summaries |
| `GET /api/integration/archive/{month}` | compact archive month payload |

All accept `start`, `end`, `bbox`, and repeated `sensor` parameters. The
`firms` adapter also accepts `max_distance_km`, `pair_minutes`, and
`max_minutes`; it computes matches on demand and does not persist a run.
Archive endpoints accept `YYYY-MM` for `start`/`end` (summary) or in the path
(month), plus `bbox` and `country`.

## Exports

### `POST /api/exports` *(admin)*

```json
{
  "dataset": "observations",
  "format": "csv",
  "start": "2024-01-01",
  "end": "2024-01-31",
  "bbox": "33.5,-5.0,42.0,5.5",
  "sensor": "VIIRS"
}
```

`dataset` is `observations` or `harmonized`. `format` is `csv` or `geojson`.
Harmonized exports require `run_id`; if omitted, the latest completed run is
used only when one exists. The response contains `download_url`.

### `GET /api/exports`, `GET /api/exports/{uid}`, `GET /api/exports/{uid}/download`

List, inspect, and download exports. Exports are capped by `MAX_EXPORT_ROWS`
(default 500,000).
